Executive Summary

moms-game is a Next.js 15 + React 19 monolith with Prisma/PostgreSQL, Stripe Checkout + webhooks, and OpenAI-backed chat/insights. The Opsera phased review flagged no global auth middleware and a single shared GameSave row (id = "default"), which is appropriate only for a deliberate single-tenant or demo deployment. In-memory IP rate limits protect chat/checkout/insights but do not coordinate across multiple server instances. Stripe webhook signature verification is implemented when secrets are present; missing STRIPE_WEBHOOK_SECRET returns HTTP 200 with skipped: true, which can hide misconfiguration.

What Works Well

What Works Well

Stripe webhook uses signature verification

stripe.webhooks.constructEvent in app/api/webhooks/stripe/route.ts validates the Stripe signature before fulfilling PendingCheckout — the right primitive for payment integrity.

Chat and checkout inputs are bounded

sanitizeChatMessage, pet sanitization, and JSON error handling reduce injection and oversize payloads on AI and game routes.

Explicit AI degradation

When OPENAI_API_KEY is absent, chat returns 503 with a clear message instead of failing opaquely.

Advanced Issues

Stripe webhook returns 200 when webhook secret missing

Operators may think Stripe events are processed when they are skipped. Prefer non-2xx or explicit monitoring when STRIPE_WEBHOOK_SECRET is absent in production.
